AI Research Assistant

Every question runs through two agents at once — a Doc Agent that searches only your uploaded documents, and a Web Agent that searches the live web via Google Search grounding. An Arbitrator agent then synthesizes both into one answer, labeling what came from where. Watch the pipeline run in real time below.
